# Changelog

All notable changes to GraceLoop are documented here.

## 0.1.0-alpha.1 — 2026-08-28

- Add strict scientific receipts, declared causal worlds, total outcome matrices,
  reference-frame checks, gates, and resource vectors.
- Add prior-free Pareto/minimax experiment frontiers with failure and no-call branches.
- Fix the alpha boundary at empirical `N=0` with no target, experiment, material, or
  release authority.
- Add tamper-evident, exact-member, no-clobber capsules with explain and counterfactual
  simulation commands.
- Pin the GraceGraph 0.1.0a1 public source freeze and its byte-only verification scope.
- Replace live database projections with a synthetic, network-free public example.
- Add hostile tests, public-tree privacy checks, packaging, and CI.
